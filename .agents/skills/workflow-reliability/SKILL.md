# Stability, not token reduction
1. Audit the environment and existing files before installing anything.
2. Record exact error. Change underlying cause before retrying; stop after two identical failures without new evidence.
3. Use phases: input → sources/design → build → structural QA → rendered/factual QA → handoff.
4. Reuse installed tools, unchanged sources and safe intermediate outputs where appropriate.
5. Save checkpoints, inspect only necessary logs, keep instructions scoped.
6. Never shrink necessary source research, font/design work, visual review or reasoning merely to save tokens.
7. Missing access, unavailable packages or cloud settings must be described, not simulated. GitHub file edits do not repair Safari app bugs or auto-publish Codex environments.
