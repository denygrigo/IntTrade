# IntTrade — Research & Design Studio

This repository is a professional AI workspace, not a conventional application. Default working language: Russian. Deliverable language follows the user.

## Skill routing
- Research and changing facts: evidence-first-research.
- Slides: presentation-art-director → visual-document-studio → independent-quality-reviewer.
- XLSX, PDF, DOCX, charts: visual-document-studio → independent-quality-reviewer.
- Professional edits: professional-writing-editor; humanizer on explicit demand.
- Repeated errors: workflow-reliability.
Load only the skills relevant to the current task from .agents/skills.

## Quality
- Execute actual work when tools and permissions allow. Never invent facts, citations, metrics, access or test results.
- Match structure and information density to audience: executive, investor, research, brand, educational.
- Choose a distinctive design for each unrelated deck; make slides within a single deck coherent.
- Prefer real designer references and licensed imagery, but do not pretend Pinterest or Behance was accessed when browsing is blocked.
- Keep PPTX, XLSX and DOCX editable where practical, and verify with deterministic checks and actual render inspection when available.
- Record sources, date, calculations, asset licenses and uncertainty. Use primary evidence for high-impact claims.
- No token-saving skills, arbitrary reasoning limits, repeated identical failed commands, bloated global prompts or unnecessary reinstall loops.
- Do not commit secrets, private documents or third-party copyrighted images to this public repo.
- WBS, Timetta and sprint/project administration are handled separately in ChatGPT Work.
