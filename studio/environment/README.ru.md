# Подготовленная конфигурация окружения

Это конкретная рекомендация для интерфейса Codex Cloud, **не применённая настройка**.
В сессии нет инструмента изменения/публикации окружения. Нужное подтверждение здесь
относится к штатной публикации окружения в продукте, а не к обычной работе с файлами.

- Репозиторий: denygrigo/IntTrade; ветка: codex/research-design-studio-20261022.
- Рабочий каталог: корень репозитория.
- Setup: `bash scripts/bootstrap.sh --full`.
- Node 24, Python 3.12; LibreOffice и DejaVu/Noto с кириллицей в образе.
- Секреты: для локального конвейера не нужны. Не добавлять ключи «на всякий случай».
- Пакетные домены: оставить действующий preset package_managers.
- Если нужен прямой сбор референсов, рассмотреть только нужные домены из списка ниже.
  Доступ к конкретному произведению и его лицензия всё равно проверяются отдельно.
- Не отключать TLS, не обходить proxy и не считать редактирование JSON изменением сети.

Кандидаты для точечного разрешения HTTP GET/HEAD, по выбранным источникам:

```text
www.pinterest.com
pin.it
i.pinimg.com
www.behance.net
mir-s3-cdn-cf.behance.net
dribbble.com
cdn.dribbble.com
www.pentagram.com
pentagram-production.imgix.net
```

Для исследований список первоисточников зависит от задания. Веб-коннектор может
иметь иной доступ, чем исполнение curl/скачивание файлов. Не обещать, что один
allowlist устранит авторизацию сайтов или ограничения их собственных серверов.

Опубликуйте проверенную конфигурацию на компьютере/вебе и затем выберите её на
iPhone. Коммит setup script не публикует окружение, не устанавливает глобальный
плагин и не меняет разрешения приложений.

При необходимости Inter/Lora добавьте целевой шаг:

```bash
python3 scripts/install_fonts.py --install --family inter --family lora --static --dest work/fonts
```

Рендер-команды должны использовать `FONTCONFIG_FILE` из вывода установщика.
`acceptance_full.py` делает это сам. Это не изменение глобального Fontconfig.
На устройстве пользователя наличие этих шрифтов проверяется отдельно.
